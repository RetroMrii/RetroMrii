📈 PolyBTCv2 — ML Research for Prediction Markets

Research
Python

A research and engineering project investigating whether machine-learning forecasts add reliable predictive value over market-implied probabilities in five-minute Bitcoin prediction markets.

• Built around causal data engineering, chronological evaluation, frozen model inference, and forecast calibration.
• Includes paper simulation, risk checks, execution diagnostics, and settlement/reconciliation components.
• Features a React/TypeScript research website and a read-only FastAPI local monitor.
• Research finding: The tested methods have not demonstrated a credible after-cost trading advantage. The published paired evaluation reports market Brier loss 0.123156 versus frozen HGB3 0.150580, on 93 observations from 55 markets. This is exploratory evidence, not a general conclusion about all ML approaches.

Stack: Python · scikit-learn · NumPy · FastAPI · React · TypeScript

🧠 TmotionLab — Emotion Classification & NLP Research

In Development

An NLP laboratory for exploring how text-classification models predict emotions, where they disagree, and how their failures can be examined.

• The earlier DAIR.AI single-label track includes TF-IDF + Logistic Regression, a NumPy neural model, and PyTorch TextCNN experiments.
• The codebase contains FastAPI services and a React/TypeScript interface with prediction, comparison, interpretation, metrics, and error-analysis views.
• Current direction: Transitioning to GoEmotions multi-label classification and controlled synthetic-data research. New model training and integration remain work in progress.

Stack: Python · NumPy · scikit-learn · PyTorch · FastAPI · React · TypeScript
