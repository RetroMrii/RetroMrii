## Featured Projects

### 01 — PolyBTCv2
**Machine Learning · Quantitative Research · Data Engineering**

[![Repository](https://img.shields.io/badge/View-Repository-238636?style=flat-square&logo=github)](https://github.com/RetroMrii/polyBTCv2)
[![Research](https://img.shields.io/badge/Research-Website-0969da?style=flat-square)](https://polybtc-research.vercel.app/)

A machine learning research project investigating whether predictive models can outperform market-implied probabilities in Polymarket's five-minute Bitcoin markets.

**Engineering highlights:**
- Causal data engineering and chronological model evaluation
- Market-probability baselines and gradient boosting models
- Forecast calibration and statistical evaluation
- Cost-aware paper simulation and execution diagnostics
- Reproducible research documentation
- React/TypeScript research website and FastAPI monitoring backend

**Research finding:** Current experiments have not demonstrated a statistically reliable incremental forecasting advantage over market-implied probabilities or a credible after-cost trading edge.

`Python` `scikit-learn` `FastAPI` `React` `TypeScript`

### 02 — TmotionLab
**Natural Language Processing · Deep Learning · Model Evaluation**

[![Repository](https://img.shields.io/badge/View-Repository-238636?style=flat-square&logo=github)](https://github.com/RetroMrii/TmotionLab)
![Status](https://img.shields.io/badge/Status-In_Development-d29922?style=flat-square)

An NLP research laboratory exploring how machine learning models classify emotional language, where models disagree, and which failure patterns emerge.

**Engineering highlights:**
- Classical TF-IDF and Logistic Regression baseline
- Neural network implemented using NumPy
- PyTorch TextCNN experiments
- Model comparison and error analysis
- FastAPI backend and React/TypeScript frontend
- Transitioning toward GoEmotions multi-label classification and controlled synthetic-data research

The completed earlier experiments and the new research direction are maintained as distinct development tracks.

`Python` `PyTorch` `NumPy` `scikit-learn` `FastAPI` `React`

### 04 — Kadaf
**Unreal Engine 5 · Game Development · Gameplay Architecture**

[![Repository](https://img.shields.io/badge/View-Repository-238636?style=flat-square&logo=github)](https://github.com/RetroMrii/Kadaf)
![Status](https://img.shields.io/badge/Status-Early_Development-d29922?style=flat-square)

A fast-paced, single-player FPS roguelite being developed in Unreal Engine 5.

The game is designed around advanced movement, responsive combat, hero-specific abilities, and deterministic roguelite encounters.

**Currently implemented:**
- Core player movement
- Health systems

**Planned systems:**
- Data-driven weapons and combat
- Enemy AI and encounter management
- Hero-specific abilities
- Deterministic sector generation
- Progression and persistence

Development follows a Blueprint-first workflow with C++ support and a component-oriented architecture.

`Unreal Engine 5` `Blueprints` `C++`
